# PastureStack

PastureStack is an independent community effort preserving, auditing, and modernizing the Rancher 1.6 ecosystem.

Our work focuses on:

- preserving source history, tags, licenses, and release provenance;
- making legacy components reproducible on maintained toolchains;
- documenting compatibility and migration decisions;
- improving security without silently changing legacy behavior; and
- providing a stable home for continued community maintenance.

## Project status

Repository migration is in progress. Until a repository publishes its own support matrix and release policy, treat imported code and historical tags as archival and unsuitable for new production deployments.
