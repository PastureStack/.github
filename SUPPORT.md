# Support

PastureStack is a community maintenance project and does not provide a commercial support SLA.

## Where to ask

- Reproducible bugs: open a bug report in the affected repository.
- Migration or provenance problems: use the migration issue form.
- Feature proposals: use the feature request form.
- Usage questions: use repository Discussions when enabled; otherwise open an issue clearly marked as a question.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and do not disclose sensitive details publicly.

Include the exact repository, commit or tag, operating system, container runtime, dependency versions, commands, and sanitized logs. Maintainers may close requests that cannot be reproduced or that concern unsupported historical binaries without a proposed maintenance path.
